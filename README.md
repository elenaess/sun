# Sun para Android

O Sun reúne um catálogo de animes e um player de vídeo. Requer Android 8.0 ou superior.

## Baixar o APK

Abra [Releases](https://github.com/elenaess/sun/releases) pelo celular e toque no arquivo `.apk` da versão desejada. As versões de teste usam assinatura de depuração. Compilações feitas em execuções diferentes podem exigir reinstalação, o que apaga os dados locais do app.

## Compilar no GitHub

Em [Actions → Sun APK](https://github.com/elenaess/sun/actions/workflows/android.yml), selecione **Run workflow**. Cada envio de código para `main` também gera um APK. O arquivo fica nos artefatos da execução. A primeira compilação de cada nova `versionName` na `main` também publica o APK em Releases.
